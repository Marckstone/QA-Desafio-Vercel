# QA-Desafio-Vercel

Planejamento e execução de testes do desafio de QA da Vercel, usando um método de *Living Docs + BDD + testes baseados em risco*, versionado em Git e legível por humanos e por IA.

## Fluxo

1. Salvar o enunciado em `Enunciado/`.
2. Planejar com a skill `qa-planning` → `Desafio/Descricao`, `Estrategia`, `Cenarios`.
3. Executar, registrar bugs em `Desafio/Bug-report/` e manter `Desafio/STATUS.md` atualizado.
4. Rastrear tudo em `Desafio/INDICE.md`.
