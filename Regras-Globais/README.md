# Regras-Globais

Regras de negócio/comportamento que valem para mais de uma parte do produto testado (ex.: comportamento de deploy, regras de autenticação, limites de plano). Vazia no início.

**Quando criar um arquivo aqui:** assim que uma regra for confirmada e se mostrar relevante para mais de um cenário — não espere o desafio terminar. Nome: `regra-<assunto>.md`. Conteúdo: regra, fonte (enunciado/documentação/observação), cenários que dependem dela.

**Gate da skill `qa-planning`:** ao planejar, leia todos os arquivos desta pasta e registre "aplica-se / não se aplica e por quê".
